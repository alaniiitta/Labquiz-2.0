# LabQuiz 2.0 — Prototipo completo

Aplicación base creada con React + Vite.

## Estructura funcional
- Inicio / dashboard
- 23 temas
- Página individual de tema con plantilla de contenido
- Test rápido
- Repaso de errores
- Progreso por tema
- Simulacro
- Diseño responsive para móvil
- Identidad visual azul petróleo + blanco roto + dorado

## Objetivo
La estructura está preparada para que la siguiente fase sea principalmente añadir contenido y conectar datos reales.

## Ejecutar
1. Instalar Node.js
2. `npm install`
3. `npm run dev`
