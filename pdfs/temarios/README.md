# Temarios oficiales en PDF

Sube en esta carpeta el temario teórico de cada tema. Estos archivos se usarán como fuente para redactar explicaciones específicas y verificables para las preguntas.

## Nombres de archivo

Usa dos dígitos para el número del tema:

- `tema-01-temario.pdf`
- `tema-02-temario.pdf`
- `tema-03-temario.pdf`
- `tema-04-temario.pdf`
- ...
- `tema-23-temario.pdf`

Para Función digestiva, el nombre esperado es:

- `tema-04-temario.pdf`

## Recomendaciones

- Es preferible que el texto del PDF sea seleccionable.
- Si el documento está escaneado, debe tener OCR.
- Conserva la numeración original de las páginas.
- Si un tema está dividido en varios documentos, añade una parte al nombre, por ejemplo: `tema-13-parte-01-temario.pdf`.
- No sustituyas los PDF de test que están en la carpeta superior `pdfs/`.
